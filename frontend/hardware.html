Biz sadəcə brauzerdə işləyən veb-sayt yox, masamızdakı fiziki sensoru kosmik yanğın alqoritminə bağlayan canlı bir IoT platforması qurduq:

01 // SENSOR SƏVİYYƏSİ

Fiziki Qaz və Tüstü Ölçümü

MQ-2 sensoru daxili qızdırıcısı və SnO₂ təbəqəsi ilə ətrafdakı tüstü hissəciklərini və alışqan qazları (LPG, metan, butan) hiss edərək müqavimətini dəyişir və analoq gərginlik (0 - 3.3V) hasil edir.

02 // MİKROKONTROLLER

ESP32 Firmware Emalı

ESP32-yə yüklədiyimiz C++ proqramı GPIO 34 pinindən 12-bit dəqiqliklə analoq siqnalı oxuyur, qaz qatılığına (PPM) çevirir və Wi-Fi üzərindən JSON paketi halına salır.

03 // SERVER ŞLÜZÜ

FastAPI & Elmi FHI Hesabı

Backend-dəki /api/sensor-data endpoint-i sensor datasını qəbul edərək elmi düsturumuz (FHI = 5.1 × OEF × PF × Mf) ilə birləşdirir və alovlanma təhlükəsini dərhal yenidən hesablayır.

04 // AVTOMATLAŞDIRMA

Canlı Həyəcan & AI Reaksiyası

Qaz və ya tüstü konsentrasiyası kritik həddi keçdikdə dashboard dərhal qırmızı xəbərdarlıq rejiminə keçir və heyət üçün avtomatik boğucu qaz tövsiyəsi çıxarır.

Nələr var? (Mövcud Avadanlıq və Komponentlər)

BÜTÜN 6 KOMPONENT İŞLƏK VƏZİYYƏTDƏDİR
MÖVCUDDUR ✓

ESP32 NodeMCU V3 Plata

Xtensa Dual-Core 32-bit LX6 mikroprosessor (240 MHz). Daxili 802.11 b/g/n Wi-Fi modulu ilə yerli şəbəkəyə qoşulur və REST API ilə məlumat ötürür.

MÖVCUDDUR ✓

MQ-2 Qaz & Tüstü Sensoru

SnO₂ elektrokimyəvi sensor təbəqəsi ilə təchiz edilib. LPG, i-butan, propan, metan, spirt və tüstü hissəciklərinə qarşı yüksək həssaslığa malikdir.

MÖVCUDDUR ✓

USB Güc və UART Şlüzü

Platanı 5V stabil cərəyanla təmin edir və eyni zamanda 115200 baud sürətində serial monitor diaqnostika konsolu ilə əlaqələndirir.

MÖVCUDDUR ✓

Dupont Naqillər (Female-to-Female)

Lehimləmə tələb etmədən VCC, GND və AOUT pinlərini birbaşa ESP32-nin VIN, GND və GPIO 34 pinlərinə bərkidən etibarlı montaj naqilləri.

MÖVCUDDUR ✓

C++ Arduino Firmware

hardware/esp32_mq2_firex.ino — Wi-Fi itəndə avtomatik yenidən qoşulan, non-blocking göndəriş dövrəsi və LED diaqnostikası olan kod bazası.

MÖVCUDDUR ✓

FastAPI Real-Time Telemetriya API

Gələn paketləri saniyənin onda birində emal edən POST /api/sensor-data və brauzerə ötürən GET /api/sensor-live endpointləri.

Fiziki Bağlantı Şeması və Pin Xəritəsi

Aşağıda hazırladığımız yüksək dəqiqlikli dövrə xəritəsi göstərilib. Sistem cəmi 3 Dupont naqili ilə lehimləməsiz quraşdırılır:

Şəkil 1.1: ESP32 NodeMCU və MQ-2 Modulunun Naqil Arxitekturası

Dövrə Spesifikasiyası və Təhlükəsizlik

MQ-2 sensorunun daxili qızdırıcısı təxminən 5V gərginlik tələb edir, buna görə sensorun VCC xətti ESP32-nin VIN pininə (USB 5V xətti) qoşulub. Analoq çıxış isə 0–3.3V diapazonunda təhlükəsiz siqnal ötürür.

MQ-2 PİNİ ESP32 PİNİ FUNKSİYA & GƏRGİNLİK
VCC (Pin 1) VIN +5V DC Sensor Qızdırıcı Qidalanması
GND (Pin 2) GND Ümumi Torpaqlama Referansı
AOUT (Pin 4) GPIO 34 ADC1 Channel 6 (12-bit Analoq Giriş)
Vacib mühəndislik arqumenti: Niyə məhz GPIO 34? ESP32-də Wi-Fi modulu işləyərkən ADC2 pinləri (GPIO 0, 2, 4, 12, 13, 14, 15, 25, 26, 27) Wi-Fi drayveri tərəfindən məşğul edilir və analoq oxunuş xəta verir. GPIO 34 isə ADC1 blokuna aiddir və Wi-Fi zamanı fasiləsiz dəqiq analoq ölçmə aparır.
